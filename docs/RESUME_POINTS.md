# DevGuard AI — Resume Points

## Project Title

**DevGuard AI — AI-Assisted Code Security & Review Platform**

**Stack:** Python, FastAPI, React, TypeScript, SQLAlchemy, PostgreSQL, SQLite, JWT, Docker, Recharts, pytest

## Recommended Resume Bullets

- Built a full-stack **developer-security platform** that performs deterministic source-code analysis and returns explainable, line-level security and maintainability findings with severity classification, remediation guidance and a 0–100 code-health score.
- Designed a **deterministic-first analysis architecture** using pattern-based rules and Python AST inspection, with an optional pluggable LLM layer supporting local Ollama or OpenAI-compatible providers without making paid APIs a core dependency.
- Implemented **JWT authentication, persistent per-user scan history, analytics dashboards, severity filtering, PostgreSQL/SQLite persistence and multi-format report generation** across PDF, HTML, Markdown, JSON, CSV, TXT and ZIP.
- Containerized the application with **Docker Compose**, added a PostgreSQL deployment path, API tests and a production React build verification workflow; final verification completed with **8 backend tests passing** and the frontend production build succeeding.

## One-Line Version

Built DevGuard AI, a full-stack code-security platform with deterministic vulnerability analysis, optional LLM review, explainable findings, JWT auth, scan analytics/history, Docker/PostgreSQL support and multi-format security reports.
